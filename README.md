# CategorizedCleaning
Rimworld mod that separates the cleaning job into clean rooms / indoor / outdoor cleaning, with a room-by-room tab on top.

- Three Work-tab columns: mop (clean rooms), sweep (interior), clean (exterior; body fluids and debris only by default).
- A "Cleaning" bottom-bar tab lists every room and cleaning zone on the map in five lanes: clean rooms, interior,
  exterior, ignored, custom. Rooms are placed by type and named by the game ("Kim's bedroom"); move one to pin it.
- Custom entries pick their filth kinds, which column cleans them (priority), and upkeep: cut plants, clear snow, haul debris.
- Cleaning zones come from Architect > Zone and work anywhere, even outside the home area.
- The mod settings hold the defaults: room type to lane, and filth kinds per lane.

The combo version can be found under the combo branch.
