# CategorizedCleaning
Rimworld mod that separates the cleaning job into clean rooms / indoor / custom zone / outdoor cleaning.

- A "Cleaning" bottom-bar tab lists every room on the map in one lane per column, placed by room type and named by the game (e.g. "Kim's bedroom"). Move a room between lanes to pin it.
- The mod settings set the defaults: which auto-detected room types (kitchen, hospital, barn, ...) land in which lane.
- A room can also be pinned by selecting a colonist and right-clicking inside it.
- The custom column cleans a zone you paint from Architect > Zone, even outside the home area.

The combo version can be found under the combo branch.
